# 校园运动队智能管理平台（产品经理作品集）

> 记录 → 管理 → 分析 → 辅助决策。服务高校排球代表队，兼容篮球/足球等运动队。

直接用浏览器打开 `index.html` 即可（纯前端，无需联网/构建/后端）。

## 覆盖页面（13 个）
首页 Dashboard · 球员管理 · 球员详情 · 训练计划（周/月视图）· 创建训练（弹窗）· 出勤管理 · 签到详情 · 阵容配置 · 比赛管理 · 比赛详情 · 数据分析 · 通知中心 · 系统设置

## 核心能力
- **训练闭环**：创建→发布→查看→签到→记录表现→形成数据→分析
- **比赛闭环**：创建比赛→配置阵容→确认首发→记录数据→结束→复盘→汇入分析
- **阵容配置**：排球场示意，点击替换 + 拖拽换人；保存前校验（缺二传/缺位置/重复球员等），仅给客观数据辅助，不自动决定首发
- **数据一致性**：所有出勤率由签到记录实时计算（今日 15/18、缺勤2+请假1=3 人、出勤率83%；球队月度出勤91%、训练完成86%、一传62%、扣球48%、发球18%）
- **权限演示**：左下角可切换「教练/队长」与「球员」视角；球员为只读
- **可视化**：自绘 SVG 图表（折线/多线/柱状/环形/迷你趋势），支持时间、位置、指标筛选

## 模拟数据
南京大学女子排球队，18 人：主攻5 / 副攻4 / 二传3 / 接应3 / 自由人3；含近一月 17 次训练、出勤记录、7 场比赛（5 场已结束 + 2 场待进行）、首发/替补与技术统计。

## 产品原则
系统只做数据记录、统计、趋势、异常提醒与信息辅助；不自动决定首发、不评价球员能力/健康、不决定训练内容，最终决策归教练/队长。

## 目录结构
- `index.html`：入口与整体布局
- `css/style.css`：南大紫设计体系、卡片/响应式
- `js/data.js`：模拟数据层 + 查询接口（含数据对象 Player/Training/Attendance/Match/Lineup/Performance）
- `js/charts.js`：SVG 图表库
- `js/components.js`：图标/弹窗/Toast/通用片段
- `js/pages/*.js`：13 个页面
- `js/app.js`：路由、导航、顶栏、通知、角色切换
